# VideoToolkit v1.7.80

本版包含智能剪辑、自动更新安装修复，并新增文件名长度控制。v1.7.78 / v1.7.79 构建未通过完整发布检查，未发布正式安装包。

- **文件名长度**：批量重命名与 Reels 批量导出新增「自定义保留字符数」。默认按目标文件系统上限；勾选后自定义文件名正文长度，扩展名保留。兼容中文和表情字符，截短重名自动加编号，防止覆盖。重命名预览、已保存方案、导出设置和合成后命名同步使用限制。
- **退出稳定性**：关闭程序时等待后台更新检查和下载线程正常结束，避免销毁仍在运行的线程导致崩溃；等待期间界面保持响应。
- **智能剪辑准确性**：自定义时长序列、智能画面识别与自动流水线统一按实际画面时间戳精确重编码，避免关键帧造成的切点偏移、片段重叠和时长不符。
- **时间与音画同步**：支持可变帧率、非零起始时间及带延迟的音轨；以视频画面时长为准，避免被较长音轨拉长。保留有效短片尾，不足一帧的余量并入相邻片段。
- **批量稳定性**：同名素材和重复任务使用独立输出目录；取消时停止媒体处理，异常或未完成的输出不替换已有成品。
- **自动更新安装**：修复安装启动时报 `cannot access local variable 'os'`；安装前等待下载线程退出并关闭独立编辑窗口，启动失败则保留当前程序并显示安装包路径。
- **下载完整性**：严格校验下载长度，修复缺少少量内容仍被认定成功的问题；每次下载使用独立临时文件，完整校验后才生成安装文件。
- **打包兼容性**：精确剪辑改用明确的源时间基准参数，修复 FFmpeg 9 拒绝旧参数导致导出失败的问题；构建时使用随包 FFmpeg 执行回归测试。

**首次升级提示**：旧版仍使用旧的安装启动代码。如果自动更新下载完成后报错，请退出软件，手动双击下载好的 v1.7.80 安装包；也可从本页下载安装包。升级到本版后，后续更新使用修复后的安装流程。

精确剪辑需要重新编码，速度比直接复制慢；场景识别仍由画面变化和阈值决定，不等同于按语句切分。

验证：37 项回归测试通过，覆盖实际 FFmpeg 导出、两种剪辑模式、可变帧率、音轨延迟、短片尾、流水线续接、取消处理、更新下载及安装启动逻辑、慢网络下退出等待、Unicode 文件名、最大文件名长度、重命名预览与实际文件一致、Reels 实际导出命名。发布构建额外检查程序启动、Whisper/ONNX、Qt 字幕绘制，以及打包后实际场景检测和精确切割。
