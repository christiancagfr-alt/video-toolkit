# VideoToolkit v1.7.76

- **字幕预览与导出一致**：语音字幕统一使用 Qt 绘制，取消长片、密集字幕自动切换渲染方式造成的字距和换行差异。
- **识别时间轴更严谨**：检查中间与尾部空档并补识别；分段交界词只保留一次；按真实画面时长校验词/句时间戳，异常结果会重试或明确报错。
- **剪辑后字幕同步**：修复裁剪成品重新识别后再次偏移；保留短词真实时长，修复重叠时不再把后面的字幕越推越晚。
- **缓存校验**：旁路词轴绑定素材与字幕内容，避免同名文件、替换后的素材误用旧字幕。
- **元数据清理与水印**：重新编码按源码率控制体积，日志显示处理前后的文件大小；纯元数据清理仍可复制音视频流。

升级提示：已有错误字幕请重新提取。旧 SRT 可通过「载入 SRT」手动导入；迁移新旁路词轴时请一起复制素材、`.words.srt` 与 `.words.json`。语音识别仍可能听错或漏词，补识别后的可疑空档会记录在日志中，供试听核对。

验证：25 项新增回归测试通过，覆盖中间漏句、短视频超长字幕、缓存绑定、裁剪/变速、预览导出一致性及实际 FFmpeg 导出。另通过原有字幕时间轴和布局检查。
