## v1.7.63

- 批量校对可查看原字幕、带时间戳的逐句差异与校对后字幕。
- 支持从谷歌表格 / Excel 批量粘贴文案：一列按行对应，或两列“完整视频文件名＋文案”匹配；支持单元格内换行。
- 新增全选可替换项、取消全选、勾选数量及批量替换；未完成对比或修改后未重新对比的项目不会被全选。
- 修复旧字幕缓存让正在识别的任务仍显示“已提取”的问题；切换视频后旧任务结果不会覆盖当前字幕框。
- 本批全部导出成功且成品验证存在后自动移除本批任务；失败批次、新加入或更新的素材保留，不删除原素材与成品。

### 注意
- 未匹配的新文案词仍可能采用估时，替换后请试听。
- 专项测试通过；字幕回归复测通过。首次回归结束时曾出现一次 Qt 原生退出异常，复测退出码为 0。
- 沿用的 cryptography 依赖高危告警尚未在此版本修复。
