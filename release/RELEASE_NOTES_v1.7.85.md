# VideoToolkit v1.7.85

- 修复时间轴片段间空隙被导出拼接压掉的问题：保留对应黑画面和静音，避免字幕仍按工作区时钟播放、视频却变短。空隙与转场同时存在时明确提示暂不支持，避免继续生成错位成品。
- 工作区时长优先使用实际画面时长，避免播放器或容器使用较长音轨时长，导致字幕校验和视频分段采用不同时间基准。
- 归零时间戳时保留原始视频帧间隔和 PTS/DTS 关系，不再按帧序号与估算帧率重建时钟，改善变帧率素材的兼容性。
- 更新剪辑和成品缓存标识，避免复用旧逻辑产生的缓存；新增工作区、实际画面、音频时长核对日志。
- 分组合成首次默认文件名自然排序、快速声音边界，并取消勾选“不转文案”。排序、裁剪方式、是否转文案自动记忆；切换快速裁剪不再自动关闭转文案。

验证：89 项回归测试通过；16 段带空隙视频分别测试普通 AAC 和无音频；真实变帧率素材的 839 个视频包相对时间及画面时长保持一致。

原素材未修改。尚未取得原报错时完整的 16 段编辑状态，不能保证覆盖所有字幕错位原因；已有严重音画时长不一致的成品不会通过升级自动恢复，应从原素材重新导出。
