# VideoToolkit v1.7.81

本版修复批量重命名的文件操作兼容性，并保留 v1.7.80 的字幕、智能剪辑、自动更新和文件名长度功能。

- 复制改用普通文件读写，绕开 Windows CopyFile2，改善部分挂载卷的兼容性。
- 增加 Windows 长路径支持，包括中文文件名。
- 复制中断时保留源文件并清理未完成的目标文件；目标重名时不覆盖已有文件。
- 移动需复制时，完整复制后才删除源文件；属性保留失败单独提示。
- 操作失败时显示具体步骤、源路径和目标路径，方便定位挂载卷及路径问题。

尚未在用户反馈的 VC 加密电脑上实测，不能确认此次 WinError 3 的唯一根因；若仍出现问题，请提供新版的完整错误信息。
