# VideoToolkit v1.7.86

修复真实素材复现的多段剪辑严重缩短问题。

- H.264 拼接视频中途切换颜色参数时，FFmpeg 会重新初始化剪辑滤镜图，丢弃缓冲中的后续片段，却仍返回成功。本版禁止该输入重置有状态的 trim/concat 图，保留完整剪辑序列。
- 用户提供的素材已复现：162 秒工作区只输出 7.75 秒，119 秒工作区只输出约 82.75 秒。修复后剪辑结果分别为 162.125 秒和 119.708 秒，与指定编辑长度相差约一两帧。
- 剪辑缓存新增时长校验，不再仅凭文件大于 1 KB 就复用；可打开但被截短的缓存会重新生成。
- 新剪辑结果严重偏离源片段预计时长时，在字幕处理之前明确停止，并保存编辑状态与源文件时长诊断 JSON。源片段起点超出源视频时长时明确提示。
- 包含 v1.7.85 的帧时间保护、工作区画面时长基准、空隙保留及分组合成设置记忆。

不修改原素材，不通过删除大片字幕或拉伸字幕时间掩盖截短。此前已经异常的成品需要重新导出。
