# VideoToolkit v1.7.88

- 修复预览读帧时钟错误造成画面逐渐落后声音、字幕的问题；连续播放顺序解码，真正的剪辑跳点仍准确跳转，并减少逐帧重复生成字幕文本。
- 修复校对按文本词数分配词轴导致后续句子串位的问题，改按原始时间区间匹配；修复重叠词被挤成零毫秒、导致导出失败的问题。
- 读取 Gladia 返回的真实逐词时间及嵌套字幕，避免有真实词轴却退回按字长估时。
- 本地 Whisper 对少量相邻零时长词保留文字并合并；连续坍缩的无效词轴提高解码精度、关闭 VAD 并按需缩短窗口重试，不通过拉长字幕掩盖空白。
- 修复稀疏词合句跨越长停顿的问题，并增加异常长字幕提示。

验证：回归测试覆盖提取、校对、导出、预览帧率与剪辑跳点；用户 33.mp4 的失败片段及原有约 30 秒字幕空白区间已做本地模型实测。预览读帧对比中，播放到约 10 秒时，旧逻辑画面约 7.93 秒，新逻辑约 9.93 秒。

升级后需对已有异常字幕执行「重新提取」；更新不会自动覆盖人工校对内容。语音识别仍可能有错字或漏识别，保留的字幕空档需要结合声音核对。本次实测覆盖问题片段，不代表整片逐句人工验收。
