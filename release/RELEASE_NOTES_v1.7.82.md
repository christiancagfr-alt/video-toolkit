# VideoToolkit v1.7.82

修复本地 Whisper 因 `metadata_errors` 接口冲突无法识别的问题，并升级运行组件。

- 本地识别统一由随包 FFmpeg 解码为 16k 单声道浮点采样，再交给 Whisper；不再调用 faster-whisper 1.2.1 与 PyAV 19 不兼容的文件解码接口。
- 支持罗马尼亚语（ro）；本次报错与语言无关。本地处理错误不再笼统提示为密钥或配额问题。
- 智能剪辑两种模式及自动流水线跳过无法解码的附加 APAC 音轨，保留可用声音；所有音轨均不支持时停止并明确提示，不静默导出无声视频。
- 升级至 2026-11-02 查询到的最新稳定直接依赖：PySide6 6.12.0、PyAV 19.0.2、CTranslate2 4.8.4、ONNX Runtime 1.31.1、Pillow 13.0.0、OpenCV 5.0.0.93、yt-dlp 2026.10.26 等；Windows FFmpeg 为 9.0.2。完整清单见仓库 release/DEPENDENCIES_v1.7.82.json。
- faster-whisper 最新 PyPI 稳定版仍为 1.2.1，本版在应用层兼容其音频输入，不使用未发布分支。Python 构建基线保留 3.12；不升级用户电脑的显卡驱动、系统组件或已下载的模型权重。
- 新增真实音频解码检查；发布前使用公开 tiny 模型验证 CPU 推理、罗马尼亚语参数和 VAD，不上传用户素材。这不代表已评估罗马尼亚语转写准确率。

尚未使用用户原始 APAC 素材实测；已有安装若混入旧文件，可将便携包完整解压到新目录运行。
