# VideoToolkit v1.7.84

- 修复部分工作区字幕已按编辑时间轴对齐、但实际烘焙视频略短时的导出失败：先校验编辑轴，再裁切实际画面边界，记录截短和移除条数；其他字幕时间不平移、不拉伸。
- 该修正仅适用于有明确编辑轴、实际视频比编辑轴短不超过 1 秒的已有工作区字幕；新识别结果、未知来源缓存和大幅错位继续严格校验。没有用户原始素材，不能保证覆盖全部错位原因。
- 批量导出存在失败或缺失成品时保留自定义标题列表，全部成品确认生成后才清空。
- 本地 Whisper 加载失败时显示原始异常，并把完整堆栈写入软件日志；安装版不再错误提示使用 pip。此项补全诊断信息，不代表已确认或修复特定电脑上的 DLL/组件加载根因。
- 保留 v1.7.83 的 PyAV 音频输入兼容、APAC 附加音轨处理及字幕源时钟修复。

验证：新增本次三组字幕边界回归及真实短成片导出测试；发布流水线校验安装包版本、本地 Whisper 实际 CPU 推理和 Qt 字幕运行。
